# Skin Temperature Variability Analysis

MATLAB code accompanying the manuscript:

**“A Network Physiology Framework for Analysing Human Skin Temperature Dynamics in Adults”**

This repository contains MATLAB code used for the analysis of human skin temperature dynamics, including:

- Poincaré variability analysis
- detrended fluctuation analysis (DFA)
- multiscale entropy
- inverse statistics and memory analysis
- transfer entropy
- transfer-entropy lag analysis
- transfer-entropy network analysis
- Monte Carlo surrogate analysis
- transfer-entropy sensitivity analyses

Participant-level physiological data are not included in this repository.

The files are provided primarily to document the analytical code used in the study. Some scripts retain file paths, input dependencies, or settings from the original research environment. Local file paths and input locations may therefore need to be adjusted before running the code on another computer.

Individual MATLAB files contain relevant comments and attribution relating to the algorithms and functions used.

Additional transfer-entropy analyses developed during manuscript revision may be added in a later repository update.
